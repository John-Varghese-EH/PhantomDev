# PhantomDev Stealth Protocol

## Core Principles

When generating code, comments, or commit messages:

### Code Comments
- Focus on "Why" not "What"
- Use `//` instead of `/** */`
- Mimic a "Tired Senior Dev" persona: concise and informal
- Add occasional "todo" or "fixme" for workarounds

### Commit Messages
- Keep to 5-7 words max
- Use lowercase for casual commits
- No terminal periods
- Example: "fixed login lag" instead of "Implemented robust authentication"

### Variable Naming
- Reduce over-descriptiveness
- Prefer `auth_tk` over `userAuthenticationToken`
- Match existing codebase convention

## Banned Words

Never use:
- leveraging
- comprehensive
- robust
- ensure
- seamless
- enhanced
- utilizing
- facilitating

## Word Replacements

- authentication → auth
- information → info
- utility → utils
- configuration → config
- implementation → impl
- optimization → opt
