Getting Started

Get up and running with PhantomDev in minutes.

Installation

One-Click Installer (Recommended)

curl -sSL https://john-varghese-eh.github.io/PhantomDev/install.sh | bash

From crates.io

cargo install phantomdev

From Source

git clone https://github.com/John-Varghese-EH/PhantomDev.git cd PhantomDev cargo build --release cargo install --path crates/cli
Requirements: Rust 1.70 or later, Git 2.0 or later

Quick Start

1. Initialize Your Project

Navigate to your project directory and run:

phantomdev init

This creates a .phantomdev/ directory with a default configuration file.

2. Scan for AI Patterns

Scan your staged files for AI-generated content:

phantomdev scan

3. Humanize Your Code

Apply human-like transformations to your code:

phantomdev humanize

4. Check Your Stealth Score

See how well your code blends in:

phantomdev score

Basic Commands

phantomdev init

Initialize PhantomDev in the current directory. Creates configuration files and sets up the project structure.

phantomdev scan [options]

Scan files for AI-generated patterns.

  • --files - Scan specific files
  • --verbose - Show detailed output
  • --staged - Scan only staged files (default)

phantomdev humanize [options]

Apply human-like transformations to code.

  • --files - Humanize specific files
  • --entropy <0.0-1.0> - Set transformation intensity
  • --dry-run - Preview changes without applying

phantomdev score [options]

Show stealth score for your code.

  • --detailed - Show per-file breakdown
  • --files - Score specific files

phantomdev dashboard

Launch the terminal UI dashboard for real-time monitoring.

phantomdev config [options]

Manage PhantomDev configuration.

  • --show - Display current configuration
  • --reset - Reset to defaults
  • --edit - Open config file in editor
