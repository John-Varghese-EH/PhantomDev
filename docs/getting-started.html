Getting Started

Your guide to setting up and using PhantomDev for the first time.

Installation

PhantomDev provides several installation methods to get you up and running quickly.

Using Cargo

Since PhantomDev is built in Rust, the easiest way to install the CLI is via crates.io:

cargo install phantomdev

Initialization

Once installed, you can initialize PhantomDev in your local project repository:

phantomdev init

This command will create a .phantomdev/ directory with default configurations that you can tweak according to your needs.

Core Concepts

Scanning for AI Patterns

PhantomDev can analyze your code for patterns typical of AI-generated content (e.g., specific comment styles, excessive emojis, deterministic variable naming).

phantomdev scan --verbose

Humanizing Code

If your stealth score is low, use the humanizer to inject entropy into your code so it mimics human stylometry:

phantomdev humanize --entropy 0.7

Undercover Transformations

Undercover mode can rewrite commit messages and comments on the fly:

phantomdev undercover --message "feat: integrate auth endpoint"

For more detailed configurations, check the Configuration Guide.
